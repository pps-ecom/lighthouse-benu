🔦 Lighthouse Dashboard - benu.ch

Übersicht der Lighthouse-Messungen für ausgewählte Seitentypen von benu.ch.

ℹ️ Hinweise zur Interpretation der Lighthouse-Werte

Die dargestellten Werte stammen aus automatisierten Lighthouse-Tests, welche über GitHub Actions in einer standardisierten Cloud-Umgebung ausgeführt werden.

Direkte Lighthouse-Tests im lokalen Chrome Browser können von diesen Ergebnissen abweichen. Ursachen dafür sind unter anderem unterschiedliche Hardware, Netzwerke, Browser-Versionen, Lighthouse-Versionen sowie der Zeitpunkt und Standort der Messung.

Zur besseren Vergleichbarkeit werden zusätzlich zu den Lighthouse-Scores technische Performance-Kennzahlen wie TTFB, FCP, LCP, TBT und CLS erfasst und ausgewertet.
